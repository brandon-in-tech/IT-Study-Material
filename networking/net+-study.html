Start with the architecture

Five domains, clear priorities, and an eight-week study framework.

Eight-week training plan

Weeks 1–2 · Core networking

OSI/TCP-IP, subnetting every day, common ports, IPv6, Wi-Fi and Ethernet. Diagram packet flows and troubleshoot at each layer.

Weeks 3–4 · Implementation

Build Packet Tracer VLANs, trunks, inter-VLAN routing, STP and addressing. Learn routing decisions, Wi-Fi security and WAN/VPN concepts.

Weeks 5–6 · Operations & security

Create diagrams, monitoring dashboards and change tickets; practice segmentation, 802.1X, certificate validation and firewall policies.

Weeks 7–8 · Troubleshooting

Complete every failure scenario, repeat weak flashcards, capture packets, take timed mixed practice sets and revisit missed objectives.

How to use this guide

  • Study one lesson, explain it without looking, then mark it complete.
  • Complete relevant Packet Tracer or VM labs; save CLI outputs and screenshots as evidence.
  • Use flashcards daily for high-volume recall, but verify your understanding with scenario questions.
  • For every mistake, document: observed symptom → likely layer → test → interpretation → correction.
  • Use the official CompTIA exam objectives as your final coverage checklist.
