Exam blueprint

Core 1 overview

Current exam: 220-1201 (A+ V15). Up to 90 questions, 90 minutes, passing score 675 (100–900 scale). You must also pass Core 2 (220-1202) for the full A+ credential. Check CompTIA's official objectives before scheduling; domain weights are based on the 220-1201 blueprint.

Where to focus: Hardware + Hardware/Network Troubleshooting = 53% of exam weighting. Do not neglect the mobile, networking and cloud objectives; performance-based questions can span multiple domains.

This independent course explains exam-relevant concepts in original language. It is not a reproduction of CompTIA's objectives document or real exam items.

Commands, port numbers & workbench notes

Essential Windows network checks

ipconfig /all                  # Read addressing and DNS settings
ping 127.0.0.1                # Test local TCP/IP loopback
ping 192.168.1.1              # Test an example local gateway
nslookup example.com          # Query DNS
tracert example.com           # View IP path hops
netstat -ano                  # Show connections/listening sockets
powershell: Test-NetConnection example.com -Port 443

Fault isolation ladder

Power → physical link → interface status → valid local IP → default gateway → remote IP → DNS → application/port → user workflow. This is a diagnostic heuristic, not a mandatory order for every incident.
