Study plan and exam-readiness checklist

Suggested progression: build a VM environment, master CLI operations and storage, secure administration, repeatable automation and isolated incident investigation. Record evidence and verify each skill without notes.

Weeks 1–2

Foundation, shell, filesystems, boot, storage and networking. Practice commands daily.

Weeks 3–4

Accounts, permissions, package management, systemd, SSH, logs and security frameworks.

Weeks 5–6

Bash/Python, containers, Ansible, IaC and automated validation workflows.

Weeks 7–8

Repeat hands-on scenarios from memory, troubleshoot intentionally broken VMs, and practice exam-style reasoning.

Before scheduling

Review the current official objectives. Be able to explain each term, identify the safest next command, predict output, diagnose failures, and recover a Linux VM without copying a script blindly.

Command reference and service troubleshooting

System inventory

uname -r
cat /etc/os-release
lscpu
lsblk -f
free -h
systemctl --failed

Networking

ip -br addr
ip route
getent hosts example.com
ss -tulpen
dig example.com
resolvectl status

Storage and access

findmnt -T /var
df -hT
df -i
sudo lvs
namei -l /etc/hosts
getfacl /etc/hosts

Security and logs

journalctl -b -p warning
ss -lntup
sudo nft list ruleset
sudo ausearch -m AVC -ts today
sudo visudo -c

Distribution differences

Use apt/dpkg on Debian-family systems; dnf/rpm on RPM-family systems. Network and service tools vary by distribution: NetworkManager, Netplan, ssh or sshd, firewalld, UFW, SELinux and AppArmor are not universal.
